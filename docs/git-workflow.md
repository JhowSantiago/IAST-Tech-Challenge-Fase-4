# Versionamento Git

O repositório foi versionado com commits atômicos diretamente na branch `main`. As mensagens seguem o padrão em português com verbo no gerúndio (`add:`, `chore:`, `test:`, `docs:`), refletindo cada incremento funcional da construção da solução.

Exemplos do histórico:

- `chore: adicionando configuracao inicial e requirements com langchain`
- `add: adicionando limpeza de texto e loader da base olist`
- `add: adicionando embeddings openai e indexacao vetorial com faiss`
- `add: adicionando transformacao de query e recuperacao semantica`
- `add: adicionando pipeline rag com grounding e recusa de escopo`
- `add: adicionando cli para ingestao, busca e avaliacao do rag`
- `test: adicionando testes unitarios de limpeza, busca faiss e pipeline rag`
- `add: adicionando base tratada da olist e relatorios de auditoria`
- `add: adicionando notebooks de preparacao da base e exploracao do rag`
